# Security Policy

## Supported version

Security fixes target the latest release on the default branch.

## Private reporting

Use GitHub's private security advisory feature for vulnerabilities in CTFKit itself. Include affected
versions, impact, minimal reproduction steps, and recommended remediation. Do not publish an unpatched issue
before maintainers have had reasonable time to investigate.

## Authorized use

CTFKit is intended for local labs, Capture The Flag platforms, and systems covered by explicit authorization.
It does not grant permission to scan a target. Public-address scanning requires an additional flag, but that
technical gate is not a substitute for written scope.

Reports about unrelated third-party targets, requests for offensive payloads, or damage caused by out-of-scope
use are outside this project's vulnerability-reporting scope.
